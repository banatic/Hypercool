# 압핀시간표 amc42.dat 포맷 명세

`C:\Program Files (x86)\압핀시간표\amc42.dat` — 압핀 "시간표관리"(amc42.exe, Delphi/Win32)의 학년도 데이터 파일.

이 문서는 amc42.exe 를 디스어셈블해 얻은 로더·세이버·셀 파서/직렬화 루틴을 근거로 한다. 레퍼런스 구현은 [`scripts/appin_amc42.py`](../scripts/appin_amc42.py) 이다. `--check` 를 실행하면 파일을 파싱하고 exe 와 같은 규칙으로 다시 직렬화·암호화한 결과를 원본과 비교하는데, 2026학년도 파일(536,854 bytes, 셀 41,964개)에서 바이트 단위로 일치한다.

| exe 주소 | 역할 |
|---|---|
| `0x12d5bc8` | 줄 암호화 + 버퍼 쓰기 |
| `0x12d5d98` | 줄 읽기 + 복호화 |
| `0x12d5efc` | 파일 로드 (`#hnd`…`#sjp` + 일별 줄을 문자열 그대로 보관) |
| `0x12d63f0` | 파일 저장 (메모리 구조 → 헤더 줄 재조립) |
| `0x12dc380` | 헤더 레코드 해석 (학년도, 이름표, 학생 배정) |
| `0x12d79a4` / `0x12d8d8c` | 일별 줄 파싱 / 직렬화 |
| `0x12d4a84` / `0x12d83f0` | 셀 파싱 / 직렬화 |
| `0x12df058`, `0x12df30c` | "변경된 시간" 판정, 이동·미배정 금지 검사 (`~`=고정, `*`=행사 의미 확인) |
| `0x12df9b4` | `<d.p` 로 원래 시간표 인덱스 구성 |

## 1. 암호화

- 파일은 CRLF 로 구분된 줄의 나열이다. 각 줄은 CP949 로 인코딩한 다음 줄 단위로 XOR 한다.
- 키는 `7n1bmu`(6바이트)이고, 키 위치는 **줄마다 0 부터 다시** 시작한다. 바이트를 건너뛰어도 키 위치는 매 바이트 증가한다.
- 평문 바이트 `b` 가 `b > 0x20` 이고 `b ^ key > 0x20` 일 때만 치환한다. 그 외(공백·제어문자, 또는 XOR 결과가 0x20 이하)는 평문 그대로 둔다.
- 이 규칙은 자기 역함수다. 같은 함수로 암호화도 하고 복호화도 한다. 그래서 `#`(0x23) 는 `^0x37 = 0x14` 가 되므로 원문 그대로 남는다 (`#h_d …`).

## 2. 줄 배치

| 줄 | 태그 | 필수 | 내용 |
|---|---|---|---|
| 0 | `#hnd ` | ✓ | 학년도·2학기 시작일·플래그 |
| 1 | `#hensa ` | ✓ | 학사/행사 목록 |
| 2 | `#gbsynames ` | ✓ | 근무상황(결강 사유) 목록 |
| 3 | `#sbjnames ` | ✓ | 과목 목록 |
| 4 | `#tcrnames ` | ✓ | 교사 목록 |
| 5 | `#clsnames ` | ✓ | 학반 + 담임 + 학생 선택군 배정 |
| 6 | `#tbsnames ` | 선택 | 특별실 목록 |
| 7 | `#sjp ` | 선택 | 시정표 (없으면 공백 26,364자) |
| 8… | — | ✓ | 일별 레코드. 일련일 1 부터 학년도 끝까지 한 줄에 하루씩 |

로더는 태그가 없으면 "손상된 파일 입니다." 를 띄운다. 선택 태그가 없으면 그 줄을 일별 레코드의 첫 줄로 취급한다. 일별 레코드의 첫 필드(일련일)가 순번과 다르면 역시 손상으로 판정한다.

목록형 헤더는 모두 `,` 로 항목을 나누고, 슬롯에서는 **1-based 인덱스**로 참조한다. 빈 항목도 자리를 차지한다.

### 2.1 `#hnd 학년도,2학기시작,플래그`

예: `#hnd 2026,46237,1`

- `학년도` → 시작일은 `학년도-03-01`, 종료일은 `(학년도+1)-03-01` 의 하루 전이다. 일별 레코드 수는 365 또는 366(윤년)이다.
- `2학기시작`: Delphi TDateTime 일련값(1899-12-30 기준). 46237 은 2026-08-03 이다. UI 의 "2학기 시작일" 값과 같고, 데이터에서도 2학년 선택군 과목이 이 날부터 바뀐다.
- `플래그`: `"1"` 이면 전역 바이트 `0x399d024 = 1`. 이 값을 쓰는 코드는 로드/저장뿐이라 의미는 확인하지 못했다.

### 2.2 `#hensa 종류^이름,…` — 학사/행사

종류(exe 상수 배열): `1` 행사(교과수업병행), `2` 행사(교과수업안함), `3` 고사(시험), `4` 휴가(방학), `5` 공휴일/휴업.
최대 100개, 이름은 최대 20자.

### 2.3 `#gbsynames 종류^이름,…` — 근무상황

종류: `1` 공결, `2` 사결. 예: `1^출장,1^공가,2^연가,2^병가,…`. 셀의 `#사유` 가 이 목록을 1-based 로 가리킨다.

### 2.4 `#sbjnames 과목명^학반^학반…,…`

과목명은 최대 30자이고, 나머지 `^…` 꼬리는 원문 그대로 보관한다. 꼬리는 그 과목을 수업하는 학반명 목록이다. 과목명이 빈 항목도 있다 (예: 11번). 최대 500개.

### 2.5 `#tcrnames 교사명^코드,…`

`^코드` 는 생략할 수 있다 (예: `정수영`, `지움1`). 코드는 3자리 숫자이고 의미는 확인하지 못했다. 최대 200개이며, 셀의 교사 번호는 1바이트(≤255)다.

### 2.6 `#clsnames 학년^학반명[*]@담임1[/담임2]^학생/학생…,…`

- `학반명` 은 최대 20자다. 바로 뒤에 `*` 가 붙으면 학반 플래그가 켜진다 (의미 미확인, 현재 데이터에는 없음).
- `담임1`, `담임2` 는 UI 의 "F8 담임1 / F9 담임2 입력" 에 대응한다.
- 학생 항목은 `번호@이름@b1:b2:…:bk` 형식이다. 번호는 1~50, `b` 는 최대 26개, 각 값은 1~90 이다.
  - `bk` 는 **선택과목 k군 시간에 그 학생이 들어가는 학반 행 번호**(`#clsnames` 1-based)이다. 예: 2학년 학생 `9:9:11:9` 는 1·2·4군에서 2-1 행, 3군에서 2-3 행의 수업을 듣는다는 뜻이다.
  - 검증 결과, 2학기 선택군 수업 123,095건 중 122,865건(99.8%)에서 배정된 행의 같은 시간 셀이 같은 군·같은 동시수업 묶음이었다. 1학기는 행 배치가 달라 일치율이 낮다. 즉 학생 배정은 **현재 학기** 기준이다.
  - 선택 값이 하나도 없는 학생은 저장할 때 빠진다.
- 이름에 들어갈 수 없는 문자: `` ~!@#$%^&*,`\|:;"' ``
- 학생·담임이 없는 학반 행(예: `3-10@`, `2-9@`)은 선택군 분반을 담는 **가상 행**이다.
- 최대 90개 학반.

### 2.7 `#tbsnames 특별실,…`

예: `강당,운동장,무용실,…`. 셀의 `\특별실` 이 1-based 로 가리킨다.

### 2.8 `#sjp` — 시정표

- 앞 12자는 설정값이다: `HHMM`(1교시 시작) `MM`(수업 분) `MM`(휴식 분) `D`(몇 교시 후 점심) `MM`(점심 분) `D`(마지막 교시). 예: `0830 50 10 4 60 7`. UI 폼 `TAMSJPF` 의 입력칸과 같다.
- 그 뒤로 366일 × 9교시 × 8자 `HHMMHHMM`(시작·종료) 이 이어진다. 공백이면 해당 교시가 없다. 일련일 n 의 블록은 `12 + (n-1)*72` 위치에서 시작한다. 이 오프셋은 코드에서 확인하지 못하고 데이터 정황으로 정했다: 1일(3/1)이 공백이고, 날짜 범위로 적용한 두 번째 시정이 2027-02-03 부터 연속으로 나타난다.
- 날마다 시정이 다를 수 있다 (예: 2027-02-03 이후는 08:30–09:30 … 16:20–17:20).

## 3. 일별 레코드

```
일련일,G1,G2,G3,f1,…,f8,,{학반,X,c1,c2,…,c9{학반,X,c1,…,c9…[:{학반,셀{학반,셀…]
```

- **헤더**(`{` 앞)는 exe 가 해석하지 않고 원문 그대로 보존한다 (`0x12d8d8c` 에서 `Copy(s,1,Pos('{')-1)`).
  - `일련일`: 1 = 학년도 3월 1일.
  - `G1..G3`: 1·2·3학년의 **하루 전체** 학사(`#hensa` 번호, 0 = 없음). 공휴일·방학·현장체험학습처럼 하루 종일인 행사만 여기에 기록된다. 입학식·체육대회·방학식처럼 일부 교시만 차지하는 행사는 헤더가 0 이고 셀의 `N*` 로만 나타난다.
  - `f1..f8` 과 마지막 빈 필드: 모든 날에 `1,1,1,1,1,1,1,1,` 이다. 의미는 확인하지 못했다.
- **학반 행** `{학반,X,c1..c9}`: 학반은 `#clsnames` 1-based 번호이고, 교시는 항상 9칸이다. 빈 칸은 수업이 없다는 뜻이다.
  - `X`: (학반, 날) 마다 있는 16비트 값이다. 로드/저장 외에는 쓰는 코드가 없고, 모든 행에서 0 이다.
- **`:` 뒤 미배정 수업**: 1일차 레코드에만 저장된다. `{학반,셀` 이 반복되고, 날짜와 교시가 없는 셀이다 (현재 데이터에는 없음).

## 4. 셀 문법

```
셀     := [블록 '>'] ['~'] [행사 '*'] 수업 ('/' 수업)* ['<' 일.교시]* ['|' 묶음]
수업   := 과목 '(' 교사 ['#' 사유 ['(' 결강교사]] ['\' 특별실]
과목   := [원 '+'] [새]          ; 교사·특별실도 같은 형식
```

exe 파서는 `>` → `~` → `*` → `|` → `<` 순서로 떼어낸 다음, 나머지를 `/` 로 나눠 수업마다 `\` → `#` → `(` 순서로 해석한다.

| 표기 | 메모리 | 의미 |
|---|---|---|
| `N>` | int32 `+0x00` | **선택과목 군(블록) 번호**. 2학년 1~4군, 3학년 1~6군 |
| `~` | byte `+0x04` | **고정**. 이동이나 미배정을 할 때 확인 창을 띄운다. 창체·공강 등에 쓰인다 |
| `N*` | word `+0x05` | **행사** `#hensa` 번호. 이 셀은 이동·미배정할 수 없다. 원래 수업 정보는 뒤에 그대로 남는다 |
| `/` | 수업 배열 | **분반**. 한 셀에 수업이 여러 개 (UI "F6 수업반추가(분반)") |
| `원+새` | word/byte 쌍 | **변경 이력**. `원` = 기초시간표 값, `새` = 현재 값. `+새` 는 원래 빈 칸에 새로 넣은 것, `원+` 는 삭제된 것 |
| `#r(t` | byte 2개 | **결강 사유** `#gbsynames[r]`, 결강 교사 `t`. 보강을 넣을 때 기록된다 |
| `\R` | byte | 특별실 `#tbsnames[R]` (`원+새` 형식 가능) |
| `<d.p` | word+byte | **원래 위치**(일련일 d, p교시). 생략하면 자기 자리다. `<` 를 최대 4번 더 붙여 이동 이력을 남길 수 있다 |
| `\|N` | word `+0x24` | **동시수업 묶음 ID**. 같은 군의 같은 시간 수업들이 같은 ID 를 가진다. 연중 고유 ID 이며 동시 이동의 단위다 |

수업 1건 구조(10 bytes): `+0` 결강교사, `+1` 사유, `+2` 과목, `+4` 원과목, `+6` 교사, `+7` 원교사, `+8` 특별실, `+9` 원특별실.

"변경된 시간"(`0x12df058`)은 다음 중 하나가 참이면 성립한다. 셀의 날·교시가 원래 위치와 다르거나, 어느 수업이든 `원과목≠과목` 이거나 `원교사≠교사` 이다.

### 예시

| 셀 | 해석 |
|---|---|
| `4(28` | 과목 4, 교사 28 |
| `10(50\1` | 과목 10, 교사 50, 특별실 1(강당) |
| `3>19*14(61\|1` | 선택 3군, 행사 19(대체공휴일) 덮임, 과목 14·교사 61, 동시수업 묶음 1 |
| `~64(` | 고정, 과목 64(창체), 교사 없음 |
| `24(20+22#5(20` | 과목 24, 교사 20→22 보강, 사유 5(특별휴가), 결강 교사 20 |
| `2>13(32<11.3` | 선택 2군, 과목 13·교사 32, 원래는 3/11 3교시 수업 (이동/교체됨) |
| `4>20(46\5+<6.1` | 특별실 5 해제(원 5 → 없음), 원래 3/6 1교시 |
| `23(12#6(12<10.1<10.5` | 원래 위치 3/10 1교시, 추가 이력 3/10 5교시 |

## 5. 해석 시 주의

- **학반 행과 학생 시간표는 다르다.** 선택군 시간에 2-1 행에 적힌 과목은 그 시간 군 분반 중 하나일 뿐이다. 실제로 2-1 학생들은 `#clsnames` 의 `bk` 에 따라 여러 행으로 흩어진다. 학반 시간표를 보여줄 때는 "선택 N군" 으로 표시하거나, 학생별로 `bk` 를 따라가야 한다.
- **교사 시간표**는 행마다 `교사`(현재 값)를 모으면 된다. `원교사` 를 쓰면 보강/교체가 반영되지 않는다.
- **행사 셀**은 원래 수업이 뒤에 남아 있다. 종류 1(교과수업병행)이면 수업이 진행되는 것으로, 2~5 이면 수업이 없는 것으로 보는 것이 UI 의미와 맞다.
- 학년도와 날짜는 `#hnd` 에서 계산해야 한다. 윤년 학년도(예: 2027학년도, 2028-02-29 포함)는 366일이다.

## 6. 미확인 항목

| 항목 | 현재 값 | 비고 |
|---|---|---|
| `#hnd` 3번째 플래그 | `1` | 로드/저장 외 참조 없음 |
| 일별 헤더 `f1..f8` | 모두 `1` | exe 가 해석하지 않고 보존만 함 |
| 학반 행 `X` | 모두 `0` | 로드/저장 외 참조 없음 |
| 학반명 `*` | 없음 | 저장 시 `학반명*@` |
| 교사 `^코드` | 3자리 | 저장 시 비어 있지 않을 때만 기록 |
| `#sjp` 일별 오프셋 | `12+(n-1)*72` | 데이터 정황으로 정함 |

## 7. 관련 파일

- `amc42.arm`: 네트워크 클라이언트 접속 설정 (서버 주소·사용자 ID·비밀번호 해시·교사명 등을 `@` 로 구분). 시간표 데이터는 들어 있지 않다.
- `amc42.afn`, `amc42.cfg`: 작은 설정 파일이다. 시간표 해석에는 필요 없다.
